# Contributing to ResearchLoop Kit

Thank you for your interest. This project is intentionally small and easy to audit. Please keep these guidelines in mind.

## Making Changes

1. Fork the repository.
2. Create a branch for your change.
3. Make your changes. Keep them focused.
4. Run `bash scripts/verify.sh` before submitting.
5. Open a pull request with a clear description.

## Principles

- Keep the base prompt (`AGENTS.md`) domain-neutral.
- Move domain-specific content into templates or the research brief.
- Prefer evidence and acceptance gates over motivational wording.
- Keep templates short and scannable.
- Run `bash scripts/verify.sh` to catch structural problems.

## Reporting Issues

Open a GitHub issue with:

- what you expected,
- what happened instead,
- the steps to reproduce.
